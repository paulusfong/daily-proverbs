## 🎨 Production Tips for 30-Second Videos

### Keep It Tight
- One idea per 5 seconds
- No wasted frames
- Cut aggressively
- Speed up slow parts (1.5x)

### Hook in 3 Seconds
- Start with surprising fact
- Show unique feature immediately
- Ask relatable question
- Use pattern interrupt

### Visual Hierarchy
```
Priority:
1. Main action (80% screen)
2. Text overlay (readable from mobile)
3. Branding (subtle, corner)
```

### Text Guidelines
- **Font size:** Huge (1/10 of screen height)
- **Duration:** 2-3 seconds per text
- **Animation:** Smooth, quick
- **Contrast:** White text + dark shadow

### Pacing
```
0-3s:  Hook (grab attention)
3-25s: Value (show features fast)
25-30s: CTA (clear next step)
```

### Music Selection
- **Start immediately** (no silence)
- **Match energy** to content
- **Beat sync** transitions
- **Fade out** on CTA

## 🎬 Quick Recording Checklist

### Before Recording (30-sec version)
- [ ] Script memorized/planned
- [ ] Browser clean (no tabs/bookmarks)
- [ ] App loaded and tested
- [ ] Recording at 60fps (smooth)
- [ ] Vertical format (9:16) set
- [ ] Lighting good
- [ ] No notifications enabled

### During Recording
- [ ] Quick, deliberate actions
- [ ] Let key moments breathe (2-3 sec)
- [ ] Smooth transitions
- [ ] Show, don't tell
- [ ] Keep mouse movements minimal

### After Recording
- [ ] Cut ruthlessly (every frame counts)
- [ ] Add large text overlays
- [ ] Sync music to beats
- [ ] Add captions (auto or manual)
- [ ] Export 1080x1920 (vertical) or 1080x1080 (square)
- [ ] Test on mobile device
- [ ] Check text readability
