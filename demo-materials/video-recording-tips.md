# Video Recording Tips & Tools

## 🎥 Recording Software

### Free Options

#### OBS Studio (Windows/Mac/Linux)
**Best for:** High-quality recordings, streaming
- Download: https://obsproject.com/
- Settings:
  - Resolution: 1920x1080
  - FPS: 30 or 60
  - Encoder: H.264
  - Bitrate: 8000-12000 Kbps

#### QuickTime Player (Mac)
**Best for:** Simple, quick recordings
- File → New Screen Recording
- Select area or full screen
- Built-in, no installation needed

#### Xbox Game Bar (Windows 10/11)
**Best for:** Quick Windows recordings
- Press Win+G to open
- Click record button
- Saves to Videos/Captures

#### SimpleScreenRecorder (Linux)
**Best for:** Linux users
- sudo apt install simplescreenrecorder
- Easy setup wizard
- Good performance

### Paid Options

- **Camtasia** - Full editing suite
- **ScreenFlow** (Mac) - Professional results
- **Snagit** - Quick editing included

## 🎬 Recording Setup

### Before Recording

1. **Clean Your Desktop**
   - Close unnecessary applications
   - Hide desktop icons
   - Clear browser cache
   - Close extra browser tabs

2. **Browser Setup**
   - Hide bookmarks bar (Ctrl+Shift+B)
   - Set zoom to 100%
   - Use incognito/private mode (fresh state)
   - Maximize window or set specific size

3. **App Preparation**
   - Clear localStorage (fresh start)
   - Prepare sample verses
   - Plan navigation flow
   - Test all interactions

4. **Audio Setup** (if narrating)
   - Test microphone levels
   - Reduce background noise
   - Use pop filter if available
   - Record in quiet room

### Recording Tips

1. **Smooth Mouse Movement**
   - Move slowly and deliberately
   - Pause briefly before clicking
   - Show hover states
   - Avoid rapid movements

2. **Timing**
   - Pause 2-3 seconds on each view
   - Allow animations to complete
   - Show loading states briefly
   - Don't rush transitions

3. **Highlighting**
   - Enable cursor highlighting
   - Use mouse to guide attention
   - Circle important features
   - Point to key elements

4. **Pacing**
   - Speak clearly and slowly
   - Match actions to narration
   - Pause between sections
   - Review script beforehand

## 🎙️ Audio Recording

### Narration Tips

- Write script beforehand
- Practice 2-3 times
- Speak at 80% normal speed
- Enunciate clearly
- Smile while speaking (sounds friendlier!)

### Microphone Settings

- Position 6-8 inches from mouth
- Use pop filter
- Record in WAV first (edit to MP3 later)
- Set gain to avoid clipping
- Test with sample recording

### Audio Software

- **Audacity** (Free) - Full editing
- **GarageBand** (Mac) - Easy to use
- **Adobe Audition** - Professional
- **Ocenaudio** - Simple and effective

## ✂️ Editing Tips

### Basic Editing

1. **Trim**
   - Remove dead space at start/end
   - Cut mistakes or pauses
   - Tighten transitions

2. **Speed Up**
   - Speed up slow loading (1.5-2x)
   - Use time-lapse for repetitive actions
   - Keep important moments real-time

3. **Add Text**
   - Feature names
   - Key benefits
   - URLs/links
   - Call-to-action

4. **Transitions**
   - Fade in/out
   - Cross-dissolve between sections
   - Smooth cuts
   - Don't overuse effects

### Advanced Editing

- Color correction
- Add zoom effects on important elements
- Picture-in-picture for mobile demo
- Split screen comparisons
- Animated overlays

## 📤 Export Settings

### YouTube/Vimeo
```
Format: MP4
Codec: H.264
Resolution: 1920x1080 (1080p)
Frame Rate: 30fps or 60fps
Bitrate: 12-15 Mbps
Audio: AAC, 192-256 kbps
```

### Social Media

#### Twitter/X
- Max duration: 2:20
- Max size: 512MB
- Format: MP4
- Resolution: 1280x720 or 1920x1080

#### LinkedIn
- Max duration: 10 minutes
- Max size: 5GB
- Format: MP4
- Aspect ratio: 1:2.4 to 2.4:1

#### Instagram Feed
- Duration: Up to 60 seconds
- Aspect ratio: 1:1 (square) or 4:5
- Format: MP4
- Resolution: 1080x1080 or 1080x1350

#### Instagram Stories/Reels
- Duration: 15-90 seconds
- Aspect ratio: 9:16 (vertical)
- Format: MP4
- Resolution: 1080x1920
