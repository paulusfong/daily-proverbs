## 📝 Recording Tips

### Before Recording:
- [ ] Clear browser cache for clean demo
- [ ] Close unnecessary browser tabs
- [ ] Hide bookmarks bar
- [ ] Set browser zoom to 100%
- [ ] Prepare verses to demonstrate
- [ ] Test audio levels
- [ ] Have script ready

### During Recording:
- Speak clearly and at moderate pace
- Use smooth mouse movements
- Pause briefly between actions
- Highlight cursor for visibility
- Show loading states briefly
- Demonstrate real-time interactions

### After Recording:
- Add captions/subtitles
- Include background music (optional, soft)
- Add smooth transitions
- Include text overlays for key features
- Export in high quality (1080p)

## 🔗 Export Settings

**Recommended:**
- Format: MP4 (H.264)
- Resolution: 1920x1080 (1080p)
- Frame Rate: 30fps or 60fps
- Bitrate: 8-12 Mbps
- Audio: AAC, 192 kbps

**For Social Media:**
- Square (1:1): 1080x1080
- Vertical (9:16): 1080x1920 (Stories/Reels)
- Horizontal (16:9): 1920x1080 (Standard)
