# Manual Screenshot Guide

If you prefer to take screenshots manually, follow this guide.

## 🖥️ Desktop Screenshots (1920x1080)

### Setup
1. Open browser (Chrome/Firefox recommended)
2. Navigate to http://localhost:8080
3. Press F11 for fullscreen (or hide bookmarks/toolbars)
4. Set zoom to 100%

### Screenshots to Take

#### English - Light Theme
1. Daily verse view
2. Browse chapters view
3. Individual chapter (Chapter 1)
4. Favorites view (empty)

#### Chinese - Light Theme
1. Daily verse view (switch to 中文)
2. Browse chapters view

#### Spanish - Dark Theme
1. Switch to Español
2. Toggle to dark theme
3. Daily verse view
4. Browse chapters view

#### French - Dark Theme
1. Switch to Français
2. Daily verse view

---

## 📱 Mobile Screenshots (375x812 - iPhone 14 Pro)

### Setup
1. Open Chrome DevTools (F12)
2. Click device toolbar (Ctrl+Shift+M)
3. Select "iPhone 14 Pro" from dropdown
4. Set zoom to 100%

### Screenshots to Take

#### Each Language (EN, ZH, ES, FR)
1. Daily verse - Light theme
2. Daily verse - Dark theme
3. Browse view
4. Favorites view

**How to capture:**
- Chrome: Ctrl+Shift+P → "Capture screenshot"
- Or use OS screenshot tool

---

## 📱 Tablet Screenshots (1024x768 - iPad)

### Setup
1. DevTools → Device toolbar
2. Select "iPad" or set custom 1024x768
3. Take screenshots of key views

---

## 🎨 Pro Tips

### Composition
- Center important content
- Leave some padding around edges
- Show cursor only when demonstrating interactions
- Keep browser chrome minimal

### Consistency
- Use same sample verses across screenshots
- Keep consistent theme/language per section
- Maintain same zoom level
- Use same browser

### Quality
- PNG format for lossless quality
- Full screen capture (no browser UI)
- High resolution displays preferred
- Check for any rendering issues

### Annotations (Optional)
- Add arrows to highlight features
- Circle important UI elements
- Add text callouts
- Use consistent annotation style

---

## 🛠️ Recommended Tools

### Screenshot Tools
- **Mac:** Cmd+Shift+4 (area), Cmd+Shift+3 (full)
- **Windows:** Win+Shift+S (Snipping Tool)
- **Linux:** Shift+PrtSc (Gnome Screenshot)
- **Chrome:** Built-in DevTools screenshot

### Annotation Tools
- **Skitch** (Mac/Windows)
- **Greenshot** (Windows)
- **Flameshot** (Linux)
- **Markup** (Mac built-in)

### Organization
Save files with this naming convention:
```
{device}-{language}-{theme}-{view}.png

Examples:
desktop-en-light-today.png
mobile-zh-dark-browse.png
tablet-es-light-favorites.png
```
