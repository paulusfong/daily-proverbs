## 🎬 Recommended Script: #1 (Feature-Focused)

**Best for:** TikTok, Instagram Reels  
**Duration:** 30 seconds  
**Style:** Fast, energetic, visual

### Quick Summary
```
Hook    (3s): Logo + "Daily Wisdom in Your Pocket"
Lang    (5s): Quick language switching ✨
Theme   (5s): Light/dark toggle 🌙
Browse  (5s): Scroll chapters (1-31)
Offline (5s): Airplane mode works! ✈️
Heart   (5s): Save favorites ❤️
CTA     (2s): "Try FREE • Link in bio"
```

### What You'll Show
1. App opens with smooth animation
2. Tap language: EN → 中文 → Español → Français
3. Tap moon: Light theme → Dark theme
4. Tap Browse: Scroll through 31 chapters
5. Enable airplane mode: App still works!
6. Tap heart: Favorite saves with animation
7. End screen: Logo + URL

### On-Screen Text (Large & Bold)
- "4 Languages ✨" (at 5s)
- "Light or Dark 🌙" (at 10s)
- "31 Chapters" (at 15s)
- "Works Offline ✈️" (at 20s)
- "Save Favorites ❤️" (at 25s)
- "Try FREE 👆 Link in bio" (at 28s)

### Music
- **Type:** Upbeat, modern electronic
- **BPM:** 120-140
- **Examples:** 
  - "Happy" instrumental
  - "Inspiring" background music
  - Trending TikTok audio (if appropriate)

## 🎥 Recording Workflow (30-sec version)

### 1. Setup (5 minutes)
```bash
✓ Open http://localhost:8080
✓ Clear browser cache
✓ Hide bookmarks bar (Ctrl+Shift+B)
✓ Set browser to 100% zoom
✓ Close other tabs
✓ Enable "Do Not Disturb"
✓ Start screen recorder (OBS/QuickTime)
```

### 2. Record Actions (30 seconds - one take!)
```
□ 0-3s:  Show app loading with logo
□ 3-8s:  Click language dropdown, switch EN→ZH→ES→FR
□ 8-13s: Click theme toggle, light→dark
□ 13-18s: Click Browse, scroll chapters, click one
□ 18-23s: Toggle airplane mode ON, app still works!
□ 23-28s: Click heart to favorite, see animation
□ 28-30s: Show end screen with URL
```

### 3. Edit (15 minutes)
```
□ Import video into editor
□ Add text overlays (see above)
□ Add background music (fade in/out)
□ Cut any dead space
□ Speed up slow parts (1.2-1.5x)
□ Add transitions (quick cuts)
□ Color grade (slight boost)
□ Add end screen (2-3s)
```

### 4. Export (2 minutes)
```
Format:     MP4 (H.264)
Resolution: 1080x1920 (vertical for IG/TikTok)
            OR 1080x1080 (square for multi-platform)
Frame Rate: 30fps or 60fps
Bitrate:    8-10 Mbps
Audio:      AAC, 192 kbps
```

### 5. Post (5 minutes)
```
□ Upload to platform
□ Add caption (see below)
□ Add hashtags (10-15 relevant tags)
□ Add location (if applicable)
□ Tag relevant accounts
□ Post!
□ Pin a comment with link
```

## 🎯 Call-to-Action Options

### Strong CTAs
- "Try it FREE 👆" (implies value)
- "Link in bio 👇" (standard, works)
- "Swipe up to try" (Stories)
- "Tap here 👉 [URL]" (direct)

### Weak CTAs (Avoid)
- "Check it out" (vague)
- "Let me know what you think" (passive)
- No CTA at all (missed opportunity)

### Best Practice
```
Primary CTA:   "Try FREE" or "Try Now"
Secondary CTA: "Link in bio"
Urgency:       Optional for launch ("Limited time")
```

## 💡 Pro Tips

### For Maximum Engagement
1. **Post consistently** (2-3x per week)
2. **Reply to every comment** (builds community)
3. **Use trending audio** (TikTok/Reels boost)
4. **Add captions** (80% watch muted)
5. **Test different CTAs** (see what converts)

### For Discoverability
1. **Use all hashtags** (10-15 relevant)
2. **Location tag** (if applicable)
3. **Tag related accounts** (don't spam)
4. **Share to Stories** (increases reach)
5. **Post at optimal times** (see above)

### For Conversions
1. **Link in bio** must work!
2. **Pin comment** with additional info
3. **Respond with link** to interested comments
4. **Create QR code** for easy access
5. **Track analytics** (which source drives traffic?)
